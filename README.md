# Cloudflare Autoreger

Быстрый многопоточный авторегер аккаунтов Cloudflare с авто-подтверждением почты и получением глобального ключа для продакшена Аркаши.

## Установка
1. Установи зависимости:
```bash
pip install -r requirements.txt
playwright install chromium
```
2. Настрой параметры в `config.py` (потоки, пароли, файлы результатов).
3. Добавь прокси в `proxies.txt` (поддерживается `ip:port` или `user:pass@ip:port`).

## Запуск
```bash
# Бесконечный режим в N потоков
python main.py

# Регистрация конкретного количества аккаунтов
python main.py --count 10

# Дебаг режим (показывает браузер и подробный лог)
python main.py --count 1 --debug
```

Результаты сохраняются в файл `results.txt`.
