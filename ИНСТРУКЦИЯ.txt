============================================================
1. КАК РАБОТАЕТ СОФТ
============================================================
1. Берет почту из emails.txt и прокси из proxies.txt.
2. Решает Turnstile капчу через AnySolver за 5 секунд.
3. Регистрирует пользователя в Cloudflare через твой прокси.
4. По API NotLetters перехватывает письмо и подтверждает почту.
5. Запрашивает OTP-код, забирает его из письма и получает 
   Global API Key.
6. Сохраняет готовый аккаунт сразу в results.txt и results.json.
7. МГНОВЕННО удаляет готовую почту из emails.txt.

============================================================
2. ЧТО НУЖНО ПОПОЛНЯТЬ И РАСХОДНИКИ
============================================================

1) СЕРВИС КАПЧИ: AnySolver.com
   - Зачем: решает Turnstile капчу при регистрации и ключе.
   - Баланс: закинуть 3-5$ в крипте (хватит на тысячи аккаунтов).
   - Ключ: скопировать Client Key (вида anysolver_01M1...).
   - Куда вставить: в config.py -> CAPTCHA_API_KEY.

2) СЕРВИС ПОЧТ: NotLetters.com
   - Зачем: прием писем, переход по ссылкам и получение кодов.
   - Баланс: подписка / баланс сервиса по их тарифам.
   - Ключ: скопировать API токен в личном кабинете.
   - Куда вставить: в config.py -> NOTLETTERS_API_KEY.

3) СПИСОК ПОЧТ: emails.txt
   - Почты от ваших доменов, привязанных к NotLetters.
   - Формат (каждая с новой строки):
     почта@домен.com:пароль
     почта2@домен.com:пароль
   - Скрипт сам удаляет из файла уже зарегистрированные почты!

4) СПИСОК ПРОКСИ: proxies.txt
   - Резидентские или серверные IPv4 прокси (HTTP / SOCKS5).
   - Браузера нет, поэтому трафика уходит всего пара килобайт.
   - Формат:
     ip:port:user:pass
     user:pass@ip:port

5. ГДЕ РЕЗУЛЬТАТЫ И ОШИБКИ
============================================================
- results.txt -> Готовые аккаунты (открывай Блокнотом):
  почта:пароль_почты:пароль_кф:Global_API_Key

- results.json -> Те же аккаунты в формате JSON.

- errors.txt -> Журнал ошибок (с временем, шагом и прокси):
  [2026-09-13 12:45:10] [почта] [Шаг] [Прокси] Текст ошибки

- autoreger.log -> Полный системный лог со всеми деталями.

============================================================
6. ЧАСТЫЕ ВОПРОСЫ (FAQ)
============================================================
* Капча висит / таймаут:
  Закончился баланс на AnySolver.com (проверь в меню start.bat пункт 7).

* Висит на ожидании письма (wait_verify_email):
  Закончился баланс NotLetters, либо письма не доходят до домена.

* Ошибка 429 или 1111:
  Прокси попал под временный лимит Cloudflare. Скрипт сам его 
  сменит на следующий из списка.

* Замерла консоль:
  Не кликай мышкой по тексту консоли (Windows ставит паузу при 
  выделении текста). Если выделилось - нажми Enter в окне консоли.
